---
description: 빌드 실패·에러 로그 진단 (배포 실패 도우미)
argument-hint: [프로젝트명]
---

`get_project_logs`로 $ARGUMENTS의 로그를 가져와 진단하라. AGENTS.md의 규칙을 기준으로 대표 실패 유형과 대조한다:

- Dockerfile/서버 설정 파일 존재 → 제거 후 재배포
- `DB_USERNAME` 등 잘못된 변수명 / DB 접속정보 하드코딩 → 자동 주입 변수(`DB_USER` 등)로 교체
- 포트 불일치(Node≠3000, Python≠8000) 또는 `localhost` 리슨 → `0.0.0.0` + 표준 포트
- 의존성 설치 실패 / 메모리 초과 / 구문 오류 → 해당 지점 수정 제안
- 인증 에러(401)를 배포 실패로 오진하지 말 것 → MCP 재인증 안내

원인·수정안·재배포 여부를 한국어로 보고한다. 무료 체험 계정은 빌드 횟수 제한(일 5회)이 있으니 원인 확인 전 재시도를 반복하지 않는다.
