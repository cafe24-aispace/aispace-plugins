# Cafe24 AI SPACE — OpenClaw/Hermes 스킬

서버에서 돌아가는 에이전트(OpenClaw·Hermes 등)가 카페24 AI SPACE에 배포·운영을 수행하게 하는 스킬입니다.

## 설치

```bash
# ClawHub에서
clawhub install aispace

# 또는 수동: skills/aispace/ 폴더를 에이전트의 스킬 디렉토리에 복사
```

## 최초 설정 (헤드리스 환경 주의)

서버에는 브라우저가 없어 인증 절차가 다릅니다. 스킬이 단계별로 안내하지만 흐름은:

1. 에이전트에게 **"AI SPACE 연결해줘"** 라고 말한다
2. 에이전트가 인증 URL을 주면 → 브라우저에서 열어 카페24 로그인·승인
3. 승인 후 이동된 페이지가 에러로 보여도 정상 — **주소창의 URL 전체를 복사해 에이전트에게 붙여넣는다**
4. 에이전트가 토큰을 저장하고 연결을 확인한다

> ⚠️ access 토큰 수명이 ~15분이라 스킬이 refresh 자동 갱신(OS crontab)을 함께 설정합니다. "예전엔 됐는데 지금 안 된다"의 최다 원인이 이 갱신 누락입니다.

## 그 다음은 그냥 대화

```
내 프로젝트 현황 보여줘
예약 접수 앱 만들어서 배포해줘
어제 배포한 앱 로그 확인해줘
```

배포가 끝나면 `https://{호스팅ID}-{프로젝트명}.mycafe24.ai`로 바로 접속됩니다 (SSL 자동).

공식 문서: https://aispacedocs-docs.mycafe24.ai
